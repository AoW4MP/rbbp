# Lords

## Created leaders

### Observer

- This lord cannot be edited

- Can be selected in any game (not recommended for scenario/story worlds)

- Multiple Observers can be selected

- If AI-controlled, loses at the start of the game

- Loses their starting city and army at the start (does not lose the game)

- No additional free city of the same faction appears on the map

- Not included in random selection

- Cannot cast spells or rituals

- All resource income per turn = 0

- Has no Whispering Stones

- Receives a one-time resource grant at the start

  - 999999 [gold]

  - 999999 [mana]

  - 99999 [fragments]

  - 99999 [essence]

  - 10 of every magic material

- Forge functionality is unlocked

- Cannot declare war/treaty/pact/alliance with players

- Players cannot declare war/treaty/pact/alliance with the Observer

- Diplomatic status with other players is permanently neutral

- Resource and artifact trading is available in diplomacy

- Can create quests

- Full map vision is unlocked

- Sees players' hidden units

- Does not see hidden neutral units
