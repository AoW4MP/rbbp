# Lords

## Created leaders

### Observer:

- Non-customizable leader

- Can be selected in any game (not recommended for story-driven realms)

- Multiple Observers can be selected

- If AI-controlled, loses immediately at game start

- Loses its starting city and army at the start (without losing the game)

- No extra free city of the same faction is placed on the map

- Never appears in random selection

- Cannot cast spells or rituals

- All per-turn resource income = 0

- Has no Whispering Stones

- Receives a one-time resource grant at the start:

  - 999999 [gold]

  - 999999 [mana]

  - 99999 Binding Fragments

  - 99999 Binding Quintessence

  - 10 of every Magic Material

- Forge functionality unlocked

- Cannot declare war/treaty/pact/alliance with players

- Players cannot declare war/treaty/pact/alliance with the Observer

- Diplomatic status with other players is permanently Neutral

- Resource and artifact trading is available in diplomacy

- Can create quests

- Full map visibility

- Sees players' hidden units

- Does not see hidden neutral units
